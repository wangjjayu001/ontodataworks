# v1.2 数据地图与问数步骤定位

数据地图采用“检索列表 → 表工作页 → 页签”的组织方式，保留字段中文释义、表信息维护和实时预览，增加同页表级血缘和字段级血缘。正式登录与访客独立空间复用同一组件；旧血缘地址兼容到地图血缘视图。

新只读接口 `/api/workspaces/{wid}/assets/{aid}/lineage` 提供当前表上下游、字段值依赖、加工表达式、查询结果和证据。仅解析已记录 SQL，结合当前真实目录展开星号、解析别名/CTE/聚合/UNION；常量和行计数独立标记，解析不唯一不猜测。WHERE/JOIN 的条件字段与值依赖分别说明。现有 TransformRun/TransformEdge、成功 QueryRun/Lineage 为依据，无新数据表或后台回填。结构变化、静态生成声明、实际重算和 SQL 静态解析不能混为一谈。

所有资源限定当前空间/数据源，并按现时对象和字段政策过滤；涉及不可读来源的 SQL 证据整体隐藏，不能泄漏跨空间表、字段、SQL或凭据。访客读取其重映射副本，模型边界保持现状。

图提供中心表、上下游展开、字段搜索、字段关联高亮、节点跳表、关系查看表达式/SQL证据。表字段和血缘互相可达；无关系、解析缺口、失败与重试明确可见。深度及查询数量有界，避免大目录阻塞。

问数动作提交后定位该需求当前交互区域，而非对话底部；异步状态或真实模型阶段变化后继续定位进度、澄清、口径、SQL、安全检查或结果。仅显式交互及其后续阶段触发；轮询相同状态、手动阅读历史不强制滚动。滚动只操作问数消息容器，尊重减少动画偏好。

当前已有未提交的访客/部署改动必须保留。v1.2 提交只纳入本次差量，相关基线副本存放忽略目录，部署逐文件备份。自动测试、真实普通/访客 API、浏览器与本机升级分别验收。
