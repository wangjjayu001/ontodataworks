# 无语义资产的问数闭环与时间约定

日期：2026-11-23。用户要求取消语义资产/问数的时区配置，并完善口径澄清→元数据→数据可用性→SQL 的链路。

现有问题：召回前的比较计算检查提前终止；未知分组在解析阶段直接阻断；澄清会清掉 bundle，而元数据候选代码仍引用旧 bundle；候选 source_check 读取了错误层级的 field_id。即使目录存在，真实链路也可能无法到达 SQL。

所有问数统一使用源系统存储时间，不再让用户配置或确认时区。资产 time_policy 保留旧 timezone 字段的读取兼容，但新建资产不要求、不提供此设置；旧发布修订不重写。

目标确认后先召回。无可用业务映射或需要多期规划时，在当前权限和固定目录快照内下探元数据。缺口径先澄清；口径明确后由异步模型步骤仅选择固定字段、计算、筛选和时间；后端检查字段/参数、同表比值及独立多期，编译只读 SQL，执行有界只读数据可用性检查，展示候选口径/来源/每期可用性，再经用户确认生成 SQL 预览及原有 Gate/单次授权。

不存在费用、成本等必要字段时，以可继续处理的澄清状态展示具体数据缺口、已检查目录和下一步；不得猜造字段或把缺数据当作语义批准问题。旧阻断运行提供重新检索入口，不要求重新提问。保留权限、只读、固定快照、结构指纹、单位和不重放约束。跨表或任意模型 SQL 仍不直接执行。

实现包含单表 SUM/AVG/COUNT/去重计数与两字段求和比值，独立多时间段和基期变化；比值零分母返回 NULL 并提示。合成与真实权限分别验收，不能以模型成功或离线测试冒充源库闭环。
