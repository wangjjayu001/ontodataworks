# 无语义资产问数闭环验收

日期：2026-11-23。对应[设计](../design/2026-11-23-query-metadata-completion-design.md)、[计划](../plans/2026-11-23-query-metadata-completion-plan.md)。

## 结果

语义资产和智能问数均取消时区设置、澄清和编译前置要求；日历范围按源系统存储时间筛选。历史资产字段保留兼容，但不再要求用户维护或确认。

比较问题不再在目录召回前因 `COMPARISON_PLANNING_UNSUPPORTED` 退出。无可用语义路径时先澄清业务含义，再调度独立 METADATA 作业检查当前权限内的固定目录，核对实际字段、来源结构和各期有效记录。有完整数据时确认临时口径并生成 SQL；缺字段、缺业务含义或无有效记录时返回具体缺口，可继续澄清、改日期或重新查找。正式证据冲突和权限失败仍阻断。

本次修复包括旧 bundle 失效后的重新召回、字段引用层级、目录请求容量、取消和租约恢复、重启后的同模型目录版本刷新、字段含义的本次确认，以及类目筛选被误当成分组的问题。模型目录刷新在后台作业内执行，HTTP 提交先返回可见进度；单次访问检查共享目录快照缓存，政策仍逐项按当前权限核对。

## 范围

当前支持本地单表目录候选的计数、去重计数、求和、平均及明确澄清的合计比值和多期变化。RATIO_SUM 的数值黄金结果在离线 DuckDB 验证；本次真实 PostgreSQL 完整 HTTP 执行验证的是评价记录数，未将其表述为 ROI 有真实数据。跨表临时公式、复杂派生口径、生产执行及自动发布语义资产仍未开放。
