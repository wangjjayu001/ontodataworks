# 问数识别进度与时间确认验收

日期：2026-11-23（Asia/Shanghai）。设计：[进度与时间确认](../design/2026-11-23-agent-progress-time-design.md)，计划：[实施步骤](../plans/2026-11-23-agent-progress-time-plan.md)。

## 问题与修改

用户报告“鞋类25年5月环比6月的roi如何”。原运行识别约 26 秒，仅有受理/识别完成两个事件；模型虽然返回对比意图，未填写基期与对比期日期，通用组件要求一个起止日期。

现在发送即显示连接提示；受理、连接、模型识别、输出校验分别显示真实阶段与已等待秒数。阶段从带认证的桥接状态接口读取，写入运行事件；不展示思维链或虚构百分比，也不重复提交模型请求。等待中提供取消入口。

比较意图保留每个独立时间段，已知年月可从原问句补全。前端以日期卡片让用户确认/编辑、交换基期、添加或删除区间。界面日期两端包含，后端仍使用结束日不含的精确区间；确认后的方向、日期、原筛选和排除条件在后续澄清中保留。历史未填日期的运行通过只读响应投影候选区间，确认前不改写历史意图。时间确认动作沿用 CAS、幂等、当前权限与审计，不产生 SQL 授权。

## 实际验证

- 15 个 Python 套件共 139 项通过，新增 9 项进度/月份比较回归：多段提取、跨年、用户反向确认、日期校验、历史响应不改写、重解析保留、多线程进度不重发模型和终态/取消保护。
- 39 项前端测试通过，Vite build 通过；覆盖多时间段、闰日、任意窗口、结束日换算、零/未知时间戳、中文状态和无百分比提示。仓库检查、Python compileall、diff 检查通过。
- 已同步本机工作台前端并重建 API/worker 镜像，重启 bridge 及工作台；实际模型契约与 API/worker 目录检查通过，数据库 Schema 不变。
- 浏览器使用真实已登录的本地工作台重问同一问题。连接提示立即出现；实测“正在识别问题、指标和时间 / 已等待 1 秒”及取消入口可见，运行事件记录 CONNECTING、MODEL_RUNNING、VALIDATING、完成。
- 实际浏览器确认两个独立月份、交换基期；把对比期结束日改成 6 月 28 日后，页面/服务端确认保留了该日期。原用户运行恢复为未确认时间卡片，供用户选择；验收误触的确认已撤销并留有事件，没有执行业务 SQL。
- 页面截图仅保留在被 Git 忽略的本机 evidence/query-progress-time 目录，公开报告不含会话、凭据或原始 HTTP。

## 实际边界

本轮真实模型识别仍约 33–35 秒；改善的是等待可感知性，未宣称降低模型推理耗时。ROI 计算、多个时间段分别执行与最终对比结果仍受既有语义/多期规划支持范围约束。本次未执行 ROI 或其他业务 SQL，不把时间交互通过表述为 ROI 结果正确。
