# 数据地图与血缘（v1.2）

在数据地图搜索中文表名、物理名称或字段，打开数据表工作页。表页采用页签组织，正式账号和已配置的访客独立空间使用相同组件，读取各自有权限的数据。

| 页签 | 用途 |
| --- | --- |
| 字段与中文释义 | 查看物理类型、可空、主外键、中文名和定义；每个字段可进入血缘 |
| 数据预览 | 按现有权限实时读取最多 100 行，保留主键排序说明 |
| 表信息 | 查看责任人、粒度、更新和质量说明，维护业务信息与元数据版本 |
| 表级血缘 | 以当前表为中心查看上游和下游，点击关联表切换中心 |
| 字段级血缘 | 选择字段或搜索中英文名称，查看值依赖、计算表达式和来源证据 |

血缘默认显示表间加工；“关系来源”可切换查询结果或全部记录，按需读取历史查询。支持上下游方向、1–3 层展开、缩放和重置。字段筛选隐藏无关空节点；点击字段、连线或证据记录，可以检查 SQL、输出表达式、条件字段及独立核验状态。旧 `#lineage` 入口转到地图的血缘入口。

## 证据与边界

加工来源包括已登记的 TransformRun/TransformEdge，以及成功且有提交回执的同步、SQL 任务；查询来源仅采用成功 QueryRun/Lineage。字段连线解析已保存 SQL，结合目录展开星号、别名、CTE、JOIN、聚合和 UNION；同步采用明确的源→目标映射，支持不同连接间同步。

“重算验证一致”“静态生成声明”“任务提交已确认”“成功查询来源”分别标记实际证据。静态字段解析不等于重新执行或业务审批；读取血缘不会执行保存的 SQL。COUNT(*) 的行依赖、常量、未唯一解析的字段和 JOIN/WHERE 条件分别说明，不猜测字段值连线。来源或目标结构已变化时，保留历史表级证据并撤下字段箭头。不能唯一解析的 SQL 保留表级来源与解析说明。

所有结果重新检查当前空间与源表权限。包含不可访问来源的 SQL 整体隐藏；不存在或跨空间表返回 404，无当前空间权限返回 403。目录血缘不建立正式语义资产，也不改变问数的发布和授权流程。

## 只读 API 契约

`GET /api/workspaces/{wid}/assets/{aid}/lineage?depth=1&include_queries=false`

`depth` 取 1–3，默认 1；`include_queries` 默认 true，前端表间加工模式传 false。返回 `api_version=catalog-lineage/1.2`：

| 字段 | 含义 |
| --- | --- |
| workspace_id / focus / depth | 空间、中心表身份 `table:<id>`、展开层数 |
| nodes | 表或查询结果；表包含物理名称、中文名称、字段类型和定义 |
| table_edges / column_edges | 来源→使用方；字段边另带源/目标字段、表达式、record_id |
| records | 已记录 SQL、SHA-256、时间、证据状态、输出字段及条件字段 |
| warnings / restricted / truncated | 解析提示、权限导致的隐藏、历史读取达到上限 |

每次最多读取最近 500 条加工记录、500 条成功任务及与中心表有关的 100 次查询。返回上限标识不代表完整历史。无需新增数据库表或迁移；已部署库需已有 v4/v5 表结构。

## 问数步骤定位

提交问题或确认澄清、时间、口径、SQL 检查和执行后，问数区域跟随本次需求的新阶段，定位模型进度、下一项确认或结果。相同状态的轮询不重复滚动；用户滚轮、触摸或方向/翻页按键会停止自动跟随。切换历史会话和新建对话会重置跟随状态，并尊重系统减少动画设置。
