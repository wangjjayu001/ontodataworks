# 问数元数据闭环实施计划

日期：2026-11-23。设计：[无语义资产的问数闭环](../design/2026-11-23-query-metadata-completion-design.md)。

1. 移除两个模块时区控件、澄清及编译前置要求，兼容历史资产字段。
2. 修正比较/维度提前阻断与候选权限/字段检查；目标确认后调度独立 METADATA 作业。
3. 支持单表比值、多期独立 SQL、基期变化和每期数据可用性核对。
4. 展示候选与数据缺口、重试检索入口；澄清后重新固定当前 bundle，避免旧引用。
5. 跑有意义的编译/空值/权限/状态测试和真实 CLI、源库、浏览器验证；同步部署、GitHub PR 与实测报告。

实施和真实模型、源库、浏览器结果见[验收报告](../reports/2026-11-23-query-metadata-completion.md)。
