# OntoDataWorks v1.1.0 · 本体数语

首次整理发布：面向 DataWorks 能力体系的数据平台与本体语义取数 Agent。

## 内容

- PostgreSQL 接入、目录/血缘、数仓建模与物理发布、SQL 开发、调度运行、质量治理、批次和数据服务。
- 本体语义资产、Metric/Binding、不可变修订、Exact/BM25/依赖图召回、逐项澄清、固定口径、确定性 SQL 规划与单次授权。
- 八模块维护清单、CODEOWNERS、模块标签、Issue/PR 模板和 GitHub CI。
- 分开的[部署 README](../../README.md)与[功能手册](../features/README.md)，显式空库初始化与仅平台运行模式。

## 验证

后端 11 组 105 项离线测试、前端 32 项测试及构建通过。独立 PostgreSQL 空库首次与重复初始化通过，五个服务就绪，15 项真实 HTTP 冒烟通过。GitHub Linux CI 的后端/仓库与前端检查通过。详情见[发布报告](../reports/2026-11-23-github-publication.md)。

## 范围

提供源码快照，部署需自行准备 Docker、Node、Python 和独立配置。阿里云 DataWorks OpenAPI/SDK、MaxCompute、OpenDataWorks MCP 尚未接通；Vector 关闭；高级同比/环比规划不支持；生产 Agent 执行禁用。当前 CLI 模型模式只适用于本地 public/synthetic 验证，本次发布检查未调用真实模型、未查询业务数仓、未做浏览器交互验收。
